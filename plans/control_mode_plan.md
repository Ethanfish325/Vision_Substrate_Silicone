# Vison_Substrate_Sillicone
# PCBA脚垫视觉检测系统方案探究

# 目标

修改当前的检测流程，使其符合当前所需的项目目标：

## 方案一：使用当前已有的轴控制配置文件，配置各个点位的轴控制系统，为每个点位实行单方案检测/多方案检测.
    方案根因：目前轴控制点位配置系统，多方案检测已有现成的代码，界面，且以稳定运行一段时间，代码已验证结构强劲成熟。

    缺点：在配置托盘时对多个PCB板的检测需要配置多个方案，有几个PCB板就有几个方案。产线设备员配置需求较为缓慢，调试也比较复杂。

## 方案二：修改当前配置流程，重构整体流程，使用复用当前流程配置结构，新增轴控制算子，拍摄分析算子，流程由上到下运行，
    方案根因：方案一中产线配置速度较慢，提出当前方案，产线设备员可以更方便的配置方案

    缺点：整体的测试流程需要全部重构，开发周期会相应延长，拍摄分析算子分析代码写死在算子里，算法精确度有待考究。


## 综合考虑：
    综合考虑后使用方案一作为实现方案，减少开发周期，且当前代码以验证可靠性。减少重新开发的结构性，资源性风险。

## 实现方案
    流程：托盘放入->按下测试按钮->托盘送入-|
        |---------------------------------------|                                   
        |-->点位检测OK->送出至二号工位->到位DI信号亮起->托盘拿起->DI信号消失->返回一号工位->等待工人放入
        |-->点位检测NG->检测检测结束后停在原地->工人查看检测图片->发送OK/NG信号--|
                                                            |---------------|    
                                                            |->OK->二号工位
                                                            |->NG->放回一号工位
